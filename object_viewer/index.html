CONCAT / JSON Workbench

v1.2

Paste a ServiceNow CONCAT("{...}") expression, plain JSON, or even a JS object literal with bare identifiers (e.g. { id: "1", tags: [a, 1] }) and click Render. It normalizes the input into valid JSON, lets you filter/edit it as a key/value table, and regenerates a valid CONCAT expression.
